# Basic Metallurgy

```
BASIC METALLURGY
│
├── ORE WASHING (Washer Chamber)
│   │
│   ├── Clean Iron
│   ├── Clean Copper
│   └── Clean Coal
│
├── ADVANCED SMELTING
│   │
│   ├── Clean Iron   → Iron Plates
│   ├── Clean Copper → Copper Plates
│   └── Clean Steel  → Steel Plates
│
└── FLUID METALLURGY (Casting)
    │
    ├── Molten Iron
    ├── Molten Copper
    └── Molten Steel
```

## Recipes

- IRON
Clean Iron → 3 plates
Clean Iron → 50 molten → 10 plates

- COPPER
Clean Copper → 3 plates
Clean Copper → 50 molten → 10 plates

- STEEL
Clean Steel → 2 plates
Clean Iron + Clean Coal → 5 Clean Steel
Clean Steel → 50 molten → 4 plates
